# 说戏使用教程

## 1. 软件是什么

说戏是一款本地优先的 AI 长篇小说写作软件。

它不替你保存作品到云端，也不需要登录。你需要自己配置一个模型 API，然后软件把作品内容直接发送给你配置的模型服务。

软件主要解决：

- 分段续写；
- 章节上下文；
- 人物 / 势力档案；
- 事件和状态同步；
- 长篇连续性；
- 阅读、书签、导出和备份。

---

## 2. 第一次启动

打开软件后会看到书架。

首页顶部有：

- 当前问候和时间；
- 书架统计；
- 剧场版 / 多选；
- 导入小说；
- 继续写；
- 新建作品；
- 外观与设置。

### 2.1 首次使用先配置 API

设置 → 模型。

1. 选择服务商；
2. 填接口地址；
3. 填 API Key；
4. 分别给通用 AI、写作 AI、聊天 AI 选模型；
5. 点“测试连接”；
6. 全部成功后关闭设置。

如果测试失败，先检查：

- 接口地址是否正确；
- Key 是否过期；
- 模型名是否存在；
- 服务商是否需要代理地址。

## 3. 书架

### 继续写

打开最近编辑的作品写作页。

### 新建作品

点“开戏”，进入横向 AI 开戏面板。

最省事的用法：

1. 在左边写一句戏核；
2. 点“一键生成整部戏”；
3. AI 会配好戏名、主题、班底、势力和关系；
4. 在右边检查、修改；
5. 点“开机”。

也可以完全手填。必填只有：

- 戏名；
- 一句话戏核。

题材、写法、视角、班底人数和字数都在“更多设定”里，可以后补。

写作模式只有：

- 导演模式；
- 轮椅模式。

两者都可以使用大纲；大纲在作品详情里。

也可以把当前戏名和戏核“先存为灵感”。

### 大纲

大纲现在是可选辅助，不需要先规划再写。

开戏时勾选：

```text
同时生成故事脊椎 + 前 5 章大纲
```

AI 会在生成班底后继续生成：

- 故事主线；
- 核心冲突；
- 阶段结构；
- 前 5 章目标；
- 每章冲突。

生成后可以在开戏面板里预览。

写作页的“本章计划”里可以直接：

- 编辑本章大纲；
- 没有大纲时用 AI 补全。

作品详情里的「大纲」随时可以打开，导演模式和轮椅模式都支持。

### 题材模板

开戏面板可以选择题材模板，默认“自动判断”。

已有：

- 修仙 / 玄幻；
- 通用；
- 都市 / 商战；
- 悬疑 / 推理；
- 言情 / 情感；
- 科幻 / 赛博；
- 历史 / 军事；
- 规则怪谈 / 无限流；
- 末世 / 废土；
- 武侠 / 江湖；
- 现实 / 年代；
- 娱乐圈 / 直播；
- 女性向 / 群像。

模板不只影响术语，还会影响 AI 生成的人物功能、常见开局、节奏节点和禁忌。

### 导入小说

支持导入已有正文，软件会尝试提取章节、人物和设定。

也可以直接把 `.txt`、`.md` 文件拖进书架窗口。松开后会先显示确认框，再开始导入。

书籍封面：鼠标移到书籍封面上，点“封面”选择 JPG / PNG / WebP；点“移除”恢复默认封面。图片会在本地裁剪压缩。

角色头像：打开角色档案，点头像下方的“设置头像”。聊天列表和聊天消息会显示头像，没设置时继续显示名字首字。

聊天背景：进入角色会客厅，选择角色后点顶部“聊天背景”。有会话时只影响当前会话，没有会话时作为聊天默认背景；可以随时清除。

### 拖拽导入技能包

把 `.zip` 技能包拖进窗口，可以直接导入技能。技能包会在导入前检查 `SKILL.md` 和可执行文件；不合格的包会被拒绝。

多选

进入批量选择模式，可批量删除、导出。

### 外观与设置

打开设置。

## 4. 写作页

写作页顶部按钮：

| 按钮 | 作用 |
|---|---|
| 书库 | 返回书架 |
| 作品状态 | 修改草稿 / 连载中 / 已完结 |
| 阅读 | 进入阅读模式 |
| 快速 / 深度同步 | 快速或深度同步当前章节 |
| 书签 | 收藏当前章、跳转书签 |
| 技能 | 打开写作技能 |
| 导出 | 导出整本或选择章节 |
| 救书 | 续写救援，分析并生成下一章 |
| 建档 | 导入建档，补全人物、势力、物种、事件 |
| 同步队列 | 打开同步 / 档案补全队列 |
| 导演模式 | 默认写作模式，大纲可在作品详情中随时补充 |
| 轮椅模式 | 极简写作模式，同样可配合大纲使用 |

### 4.1 章节列表

左侧是章节列表。

每章支持：

- 点击切换；
- 右键菜单；
- 上移 / 下移；
- 新建章节；
- 删除章节（应用内确认弹窗）；
- 查看版本历史；
- 导出本章；
- 复制章节。

### 4.2 正文编辑

正文区域支持：

- 直接编辑；
- 选中文本；
- 右键菜单；
- 实体高亮；
- 查找替换；
- 版本历史。

### 4.3 底部输入栏

底部是导演指令输入区。

左侧按钮：

| 按钮 | 作用 |
|---|---|
| 承接简报 | 查看本章承接信息 |
| 本章目标 | 设置本章推进、暴露、钩子、长度和节奏 |
| 上下文 | 查看上下文开关和 token 预算；可选 8k–128k 或不限制 |
| @ 引用 | 引用人物、势力、地点、伏笔 |
| 搜索本书 | 搜索当前作品 |
| AI 自动续写 | 不输入指令，直接生成 |
| 写作动作 | 扩写、精简、改写、加强冲突等 |
| 连续性检查 | 检查本章连续性 |
| 未回收伏笔 | 查看还没回收的伏笔 |
| 灵感与钩子 | 获取灵感和章末钩子 |
| 收起输入栏 | 收起底部输入栏 |

中间输入框：

- 输入导演指令；
- `Ctrl / Cmd + Enter` 发送；
- `@` 引用实体。

右侧：

- 字数选择；
- 发送 / 停止；
- 模型切换；
- 推理等级。

### 4.4 生成操作

生成中：

- 正文流式显示；
- 可停止；
- 可重拍；
- 生成完成后可手动编辑。

生成后建议：

1. 检查人物数量；
2. 检查位置；
3. 检查时间线；
4. 再同步。

---

### 4.5 轮椅模式

轮椅模式是一条紧凑的自动写作 Dock，高度约 58px。

从左到右：

- 运行状态；
- 第几章 / 总章数；
- 进度条；
- 每章字数与预计总计；
- 开始 / 暂停 / 继续；
- 停止；
- 设置；
- 退出。

运行中：

- 点“暂停”会在当前章完成后暂停；
- 点“继续”接着执行；
- 点“停止”会中止，已经完成的章节保留。

点齿轮打开设置：

- 生成章数（1–10）；
- 单章时的每章目标字数；
- 多章时的每章字数区间。

重要：

> 多章生成时，区间决定的是“每章”目标字数，不是总字数。

界面会同时显示预计总计，方便估算总产出。

## 5. 阅读模式

顶部按钮：

| 按钮 | 作用 |
|---|---|
| 书签 | 收藏当前章、跳转书签 |
| 朗读 | 系统朗读 |
| 目录 | 章节目录，可搜索标题 |
| 阅读设置 | 字号、行距、主题、页宽、快捷预设 |
| 全屏 | 全屏阅读 |
| 关闭 | 退出阅读模式 |

阅读模式左侧 / 右侧可切换章节。

书签会记录当前滚动位置。

阅读模式支持：

- 顶部 / 底部工具栏静止后自动隐藏，移动鼠标或按 H 恢复；
- 章末显示下一章、目录和加书签入口；
- 底部显示本章进度和预计剩余阅读时间；
- 选中文字可复制、高亮或写批注；
- 目录可搜索章节；
- 上下方向键 / PageUp / PageDown / 空格滚动，左右方向键翻章；
- ? 打开快捷键说明；
- 阅读设置里有“舒适 / 紧凑 / 大字”预设。

阅读模式没有同步按钮；同步请回写作页。

## 6. 书签

### 阅读模式

1. 点顶部书签按钮；
2. 点“收藏当前章”；
3. 输入书签名称或保留默认；
4. 自动保存当前滚动位置；
5. 点书签可跳回章节和位置。

### 写作页

1. 点顶部“书签”；
2. 收藏当前章；
3. 点书签跳转章节；
4. 点垃圾桶删除。

书签只保存在本地，不影响正文。

## 7. 写作技能

写作页顶部“技能”。

内置 6 个：

### 场景诊断

检查：

- 本场目标；
- 冲突；
- 信息释放；
- 人物位置；
- 节奏；
- 结尾。

只输出问题，不改正文。

### 对白打磨

把解释型对白改成有潜台词的对白。

保留人物语气和事件结果。

输出改写文本，需要手动复制。

### 连续性审查

检查：

- 人物认知；
- 位置；
- 时间线；
- 伤势、物品、关系；
- 与最近章节冲突。

只输出冲突列表。

### 局部润色

优先处理选中文本；
没有选中时处理本章末段。

只调整文字，不改事实。

### 去肢体动作腔

减少装饰性的挑眉、勾唇、攥拳、深吸一口气等动作套话。

保留真正改变力量关系、暴露隐瞒或推动行动的动作。

把被删除的动作改成对白潜台词、停顿、具体事务或环境。

### 章节收尾

检查：

- 本章是否收住；
- 钩子是否自然；
- 是否与下一章冲突。

输出建议，不直接写正文。

### 技能工具

技能可以读取：

- 本章正文；
- 当前选中文本；
- 角色资料；
- 事件与状态；
- 最近章节；
- 文本统计。

这些数据由软件本地收集，不联网执行脚本。

### 导入 / 导出技能

写作技能窗口左上角：

- 导入：选择 JSON 技能文件、单个 `SKILL.md` 或 `.zip` 技能包；
- 导出：导出所有自定义技能；
- 导出当前包：把当前选中的技能导出为 `.zip` 技能包。

导入的未知工具会被忽略。技能包不会执行脚本。

### 重命名与启停

自定义技能可以点“重命名”修改显示名称。

技能列表左侧勾选框支持多选：

- 全选；
- 启用；
- 停用。

停用的技能会显示为灰色，运行按钮会禁用；重新启用后恢复。

内置技能不能重命名或删除，但可以停用。

技能格式见 `docs/SKILLS.md`。

## 7.5 灵感库

左侧导航“灵感库”，或按 `Ctrl / Cmd + Alt + I` 打开。

适合保存：

- 场景；
- 台词；
- 人物；
- 设定；
- 冲突；
- 意象；
- 反转。

第一版支持：

- 快速收下一句话；
- 搜索；
- 按状态 / 类型 / 作品筛选；
- 标签；
- 编辑；
- 关联作品和章节；
- 复制；
- 插入章节末尾；
- 标记已使用；
- 删除。

“收件箱”放刚记下的内容，“发酵中”放还在想的，“已使用”和“已归档”用于整理。

灵感会随项目备份一起保存。

## 8. 同步

### 快速同步

适合日常章节。

更新：

- 摘要；
- 事件；
- 状态变化；
- 新实体；
- 线索。

不生成角色经历和审查。

### 深度同步

适合重要章节。

更新：

- 完整事件；
- 状态；
- 角色经历；
- 一致性审查。

### 自动同步

设置 → 同步。

可配置：

- 续写后自动快速同步；
- 快速同步间隔；
- 达到间隔时只同步当前章 / 回补未同步章；
- 重要剧情立即快速同步；
- 快速同步信息不足时自动深度补全；
- 同步新建实体后自动补全深度档案；
- 每章自动补全数量；
- 只自动补全重要实体；
- 暂停后台 AI 档案补全。

### 同步队列

写作页顶部“同步队列”。

可以看到：

- 同步完成 / 等待 / 失败；
- 快速 / 深度；
- 手动 / 自动 / 补同步；
- 档案补全进度。

操作：

- 暂停；
- 继续；
- 取消未开始任务；
- 重试失败任务；
- 清理已完成。

### 补同步

把未同步章节加入队列。

会弹应用内确认框，说明请求次数和费用。

## 9. 实体档案

### 角色

角色页支持：

- 新建角色；
- AI 生成角色；
- 搜索；
- 批量选择；
- 角色卡；
- 基础档案；
- 深度档案；
- 人物经历；
- 背包；
- 关联物品生成；
- 待补全筛选。

角色详情按钮：

| 按钮 | 作用 |
|---|---|
| 基础档案 | 姓名、身份、境界、装备等 |
| 深度档案 | 性格、语音、行为、知识、动态 |
| 人物经历 | 角色经历过的事件 |
| 补全深度档案 | AI 只补空白字段 |
| 关闭 | 关闭详情 |

### 势力

势力页支持：

- 新建势力；
- AI 生成势力；
- 名册；
- 设施；
- 仓库；
- 深度档案；
- 关系矩阵；
- 势力会议；
- 待补全筛选。

势力详情按钮：

| 按钮 | 作用 |
|---|---|
| 基础档案 | 名称、类型、首领、目标 |
| 深度档案 | 公开形象、真实目的、治理、资源、知识 |
| 驻地设施 | 设施、人数、资源 |
| 补全深度档案 | AI 只补空白字段 |
| 关闭 | 关闭详情 |

### 自动补档

同步发现新角色 / 势力时：

1. 先创建占位档案；
2. 同步完成后尝试补全；
3. 每章最多补配置数量；
4. 只补空白字段；
5. 失败保留占位。

## 14. 项目包导入导出

项目包用于换设备、备份或手动搬运单部作品。

### 导出

书架 → 右键作品 → “导出项目包…”。

文件扩展名：

```text
.shuoxi.json
```

包含：

- 作品信息；
- 全部章节；
- 人物、势力、事件、设定；
- 关系、伏笔、物品等。

不包含：

- API Key；
- 本机设置；
- 聊天记录；
- 同步队列。

### 导入

书架顶部 → “导入项目”。

选择 `.shuoxi.json` 文件。

软件会：

- 新建一部作品；
- 恢复章节和设定；
- 生成新的作品 ID，避免覆盖现有作品。

## 15. 设置说明

### 模型

三档 AI：

- 通用 AI：同步、建档、分析、档案；
- 写作 AI：正文、润色、标题、深度同步；
- 聊天 AI：角色聊天。

公共配置：

- 服务商；
- Base URL；
- API Key；
- Embedding 模型；
- 写作价格（默认使用内置价格，高级里可覆盖）。

每档可单独：

- 选模型；
- 选推理等级；
- 测试连接。

推理等级：

- 自动；
- 快速；
- 标准；
- 深度。

### 外观

## 17. 常见问题

### 提示没有配置 API

设置 → 模型，填写 Base URL 和 API Key。

### 测试连接失败

检查：

- 接口地址；
- Key；
- 模型名；
- 余额；
- 网络。

### 同步很慢

- 使用快速同步；
- 关闭自动深度补全；
- 降低每章自动补档数量；
- 检查所用模型速度。

### 补全档案没有内容

- 模型可能没有返回可解析 JSON；
- 换更稳定的模型；
- 确认该实体还有空白字段；
- 查看提示信息。

### 阅读器没有同步按钮

这是设计如此。同步在写作页。

### 删除章节没有系统弹窗

删除章节使用应用内确认弹窗。

### 同一台电脑能同时开两个说戏吗

不能。单实例锁会导致后启动的实例退出。
