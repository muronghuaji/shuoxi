说戏（Shuoxi）详细使用教程
版本：2.4.0
适用平台：Windows 10 / 11 x64
文档性质：本地优先 AI 长篇小说写作软件使用说明

============================================================
一、软件是什么
============================================================

说戏是一款本地优先的 AI 长篇小说写作软件。

它的核心思路不是“一键生成整本小说”，而是：

1. 你给导演指令；
2. AI 按段续写；
3. 每段读取当前章节正文；
4. 章末同步人物、事件、状态；
5. 重要章节深度补全；
6. 作者随时修改和校对。

作品数据保存在本机。
AI 通过你自己配置的模型 API 直接请求服务商。
软件不提供模型账号，也不代收 API 费用。

============================================================
二、第一次启动
============================================================

1. 打开 Shuoxi.exe。
2. 进入书架首页。
3. 先点“外观与设置”。
4. 进入“模型”页。
5. 配置 API。
6. 点“测试连接”。
7. 测试成功后关闭设置。
8. 新建作品或导入小说。

如果没有配置 API：

- 续写不可用；
- 同步不可用；
- 技能不可用；
- 实体生成不可用；
- 聊天不可用。

但本地编辑、阅读、书签、导出、备份仍然可用。

============================================================
三、设置页：模型 / API 配置
============================================================

设置页分为六个标签：

1. 模型
2. 外观
3. 角色聊天
4. 同步
5. 数据
6. 用量

------------------------------------------------------------
3.1 模型页
------------------------------------------------------------

【服务商】

选择模型服务商预设。

选择后会自动带出默认接口地址。

常见：

- DeepSeek
- OpenAI
- 硅基流动
- OpenRouter
- 自定义中转

【接口地址 Base URL】

模型 API 地址。

例如：

https://api.deepseek.com/v1

注意：

- 一般需要带 /v1；
- 中转站地址以服务商说明为准；
- 地址错误会导致测试失败。

【API Key】

填写你的密钥。

右侧眼睛按钮：

- 显示 / 隐藏 Key。

Key 只保存在本机。

【Embedding 模型（可选）】

填写兼容 OpenAI /embeddings 的模型名。

作用：

- 故事记忆语义检索。

不填：

- 使用本地关键词和实体检索。

普通作者可以先留空。

【写作价格】

用于本地费用估算。

默认使用内置价格，一般不需要手动维护。

只有两种情况下才展开“自定义价格（高级）”：

- 当前模型没有匹配到内置价格；
- 服务商调整了价格。

高级里可以填：

- 输入价格 / 百万 tokens；
- 输出价格 / 百万 tokens；
- 缓存命中输入价；
- 缓存写入价；
- 峰谷时段和折扣。

不是服务商实际账单。
余额以服务商页面为准。

【通用 AI】

负责：

- 快速同步；
- 部分深度同步；
- 实体生成；
- 档案补全；
- 大纲；
- 分析；
- 导入建档；
- 写作助手；
- 救援分析。

建议：

- 稳定；
- 便宜；
- JSON 输出可靠。

【写作 AI】

负责：

- 正文续写；
- 选中改写；
- 润色；
- 标题；
- 救援正文；
- 深度同步。

建议：

- 文笔好；
- 长上下文；
- 推理能力较强。

【聊天 AI】

负责：

- 角色单聊；
- 群聊；
- 聊天记忆；
- 语气检查。

建议：

- 便宜；
- 响应快；
- 能保持角色语气。

【模型选择】

配置接口和 Key 后，软件会自动获取模型列表。

如果获取失败：

1. 点“重新获取”；
2. 检查 Base URL；
3. 检查 Key；
4. 检查服务商是否支持 /models。

【推理等级】

每个模型单独选择：

- 自动
- 快速
- 标准
- 深度

写作可用深度；
同步和检查建议快速或标准。

【测试连接】

只发一个很小的请求。

用于验证：

- 地址；
- Key；
- 模型名。

【测试三档连接】

一次测试通用、写作、聊天三档。

【清除配置】

清空本地 API 配置。

不会删除作品。

------------------------------------------------------------
3.4 同步页
------------------------------------------------------------

【AI 续写后自动快速同步】

开启后：

- 每次续写结束会多一次快速同步请求。

默认关闭。

【快速同步间隔】

范围 1–100 章。

间隔越大：

- 越省费用；
- 中间状态越容易滞后。

【达到间隔时】

两个选项：

1. 只同步当前章（省费）
2. 回补未同步章

【每章生成本地摘要】

不调用 AI。

用开头、关键句和结尾补足上下文。

【重要剧情立即快速同步】

死亡、重伤、背叛、首领更替、战争、真相揭露等章节不等间隔。

【快速同步信息不足时自动深度补全】

快速同步发现：

- 事件达到上限；
- 状态变化达到上限；
- 新实体达到上限；

自动补一次深度补全。

【同步新建实体后自动补全深度档案】

同步发现新角色 / 势力时：

- 先建占位；
- 再自动补档。

【每章自动补全数量】

范围 1–5。

越大越慢、越贵。

【只自动补全重要角色和势力】

开启后优先补：

- 主角；
- 反派；
- 核心成员；
- 首领；
- 关键角色。

路人保持占位。

【暂停后台 AI 档案补全】

开启后：

- 同步继续；
- 自动补档停止；
- 手动补全不受影响。

【AI 运行状态】

显示：

- 并发；
- 排队；
- 本次请求次数；
- 输入 token；
- 输出 token；
- 按任务统计。

============================================================
四、书架首页
============================================================

首页显示：

- 问候；
- 日期；
- 书架统计；
- 作品列表。

顶部按钮：

【剧场版】

切换展示模式。

【多选】

进入批量选择。

可以：

- 批量删除作品；
- 批量导出。

【导入小说】

导入已有正文。

支持：

- txt；
- 自动识别章节；
- 提取人物和设定。

也可以直接把 txt 或 md 拖进书架窗口。

松开后先确认，再开始导入。

【书籍封面】

鼠标移到书籍封面。

点“封面”选择图片。

点“移除”恢复默认封面。

支持 JPG / PNG / WebP，本地裁剪压缩。

【角色头像】

打开角色档案。

点头像下方“设置头像”。

聊天列表和消息会显示头像。

【聊天背景】

进入角色会客厅。

选择角色后点顶部“聊天背景”。

有会话时只影响当前会话。

没有会话时作为聊天默认背景。

写作页拖入 txt 不会新建作品，会提示回书架导入。

【拖拽导入技能包】

把 zip 技能包拖进窗口。

可导入技能。

会检查 SKILL.md 和可执行文件。

【继续写】

打开最近作品。

【新建作品】

创建新书。

【外观与设置】

打开设置。

作品卡片按钮：

- 继续写：进入写作页；
- 作品详情：查看设定、人物、势力、事件；
- 更多：导出、删除等。

============================================================
五、新建作品
============================================================

点“开戏”。

横向面板：

左边：

- 一句话戏核；
- 补充要求；
- 调性；
- AI 一键生成整部戏。

右边：

- 戏名；
- 题材；
- 怎么写；
- 主题；
- AI 生成的班底；
- 更多设定；
- 开机。

必填只有：

1. 戏名
2. 一句话戏核

其他可以后补。

题材模板：

- 可以自动判断；
- 也可以手动选。

已有：

- 修仙 / 玄幻；
- 都市 / 商战；
- 悬疑 / 推理；
- 言情 / 情感；
- 科幻 / 赛博；
- 历史 / 军事；
- 规则怪谈 / 无限流；
- 末世 / 废土；
- 武侠 / 江湖；
- 现实 / 年代；
- 娱乐圈 / 直播；
- 女性向 / 群像。

模板会影响 AI 生成的角色功能、开局、节奏和禁忌。

大纲：

- 开戏时可以勾选“同时生成故事脊椎 + 前 5 章大纲”；
- 生成后可在开戏面板预览；
- 写作页“本章计划”里可以编辑或 AI 补全；
- 作品详情的大纲页随时可用；
- 导演模式和轮椅模式都能用大纲。

写作模式：

- 导演模式；
- 轮椅模式。

两种模式都可以使用大纲。

大纲在作品详情里。

也可以：

- 先存为灵感；
- 完全手填；
- 导入已有小说。

新建后进入写作页。

------------------------------------------------------------

例如：

“陈默发现档案被改，但不立刻揭穿范长庚。”

快捷键：

Ctrl / Cmd + J：收起 / 展开

9.2 承接简报
------------------------------------------------------------

查看本章承接信息：

- 当前人物；
- 当前地点；
- 未解决线索；

------------------------------------------------------------
9.3 本章目标
------------------------------------------------------------

- 推进；
- 暴露；
- 钩子；
- 长度；
- 节奏。

------------------------------------------------------------
9.4 上下文
------------------------------------------------------------

查看：

- 上下文预算；
- 当前 token；
- 各区块开关；
- 角色 / 势力 / 物品 / 伏笔范围。

上下文上限可调：

- 4000–128000；
- 默认 24000；
- 64k；
- 128k；
- 不限制。

选择“不限制”后，说戏不设置人为上限，但仍会按模型窗口扣掉输出预留。

例如：

- 模型窗口 128000；
- 输出预留 8192；
- 本次有效输入 119808。

如果设置的上限超过模型窗口，会自动压缩到模型窗口内，并在上下文面板提示。

不限制时仍会显示当前上下文估算 token、模型窗口、有效输入和输入费用。

被裁剪的段落会列在“本次被裁剪”里；角色状态和地点明显冲突时会出现“上下文提醒”。

模型窗口可以自动按模型名判断；也可以在工作区 → 设置 → 模型里手动填写。

------------------------------------------------------------
9.14 模型 / 推理等级
------------------------------------------------------------

可切换写作模型和推理等级。

一个章节内不建议频繁切换模型。

9.14.1 场记分析
------------------------------------------------------------

输入栏左侧的 ✦ 按钮。

点一下会先让 AI 分析这一场：

- 本场目标；
- 在场角色；
- 各自知道什么；
- 各自想要什么；
- 核心冲突；
- 必须回收的线；
- 结尾钩子。

只分析，不写正文。

分析结果可以：

- 直接修改；
- 追加到导演指令；
- 再点续写。

适合复杂章节、多人场景和容易写偏的戏。

9.15 轮椅模式

------------------------------------------------------------

轮椅模式是一条 58px 高的自动写作 Dock。

从左到右：

- 运行状态；
- 第几章 / 总章数；
- 进度条；
- 每章字数和预计总计；
- 开始 / 暂停 / 继续；
- 停止；
- 设置；
- 退出。

运行中：

- 暂停：当前章完成后暂停；
- 继续：接着执行；
- 停止：中止，已完成章节保留；
- 退出：回到导演模式。

点齿轮打开设置：

- 生成章数：1–10；
- 单章：每章目标字数；
- 多章：每章字数区间。

注意：

多章生成时，区间决定的是“每章”目标字数，
不是整批总字数。

例如：

生成 3 章，每章区间 1000–2000 字，
预计总计约 4500 字，每章分别在这个区间内取值。

Dock 会显示：

每章 1000–2000 字 · 预计总计约 4,500 字

十、阅读模式
============================================================

顶部按钮：

【书签】

打开书签面板。

【朗读】

系统 TTS 朗读。

支持：

- 播放；
- 暂停；
- 继续；
- 停止；
- 自动下一章。

【目录】

章节目录。

支持搜索标题。

【阅读设置】

调整：

- 主题；
- 字号；
- 行距；
- 页宽；
- 段间距；
- 字体；
- 实体颜色；
- 舒适 / 紧凑 / 大字预设。

【全屏】

全屏阅读。

【关闭】

退出阅读模式。

阅读模式支持：

- 工具栏静止后自动隐藏；
- 移动鼠标或按 H 恢复工具栏；
- 章末下一章和继续阅读；
- 底部本章进度和剩余时间；
- 选中文字复制 / 高亮 / 批注；
- 上下键、PageUp、PageDown、空格滚动；
- 左右方向键翻章；
- ? 查看快捷键；
- Esc 关闭面板或退出。

阅读模式没有同步按钮。
同步请回写作页。

12.10 技能结果
------------------------------------------------------------

运行后显示结果。

按钮：

- 复制：复制结果。

不会自动改正文。

------------------------------------------------------------
12.11 去肢体动作腔
------------------------------------------------------------

处理：

- 装饰性肢体动作；
- 动作套话；
- 用动作代替情绪；
- 重复的小动作。

保留：

- 改变力量关系的动作；
- 暴露隐瞒的动作；
- 推动行动的动作；
- 打断对白制造停顿的动作。

被删除的动作改成：

- 对白潜台词；
- 停顿；
- 具体事务；
- 环境细节。

输出：改写文本，需要手动复制。

------------------------------------------------------------
12.12 SKILL.md 技能包
------------------------------------------------------------

技能包结构：

技能名.zip
└─ 技能名/
   ├─ SKILL.md
   └─ references/
      ├─ 反例.md
      └─ 正例.md

SKILL.md 示例：

---
name: 去肢体动作腔
description: 减少装饰性肢体动作
category: 润色
output: rewrite
profile: writing
tools:
  - selection
  - chapter
  - characters
  - stats
---

这里写技能规则。

限制：

- 不执行脚本；
- 不联网；
- 不允许 exe、dll、js、bat 等可执行文件；
- 最多 8 个参考资料；
- 技能包文本大小有上限。

二十一、常见问题
============================================================

【问题】无法续写

检查：

1. 设置 → 模型；
2. Base URL；
3. API Key；
4. 测试连接；
5. 余额；
6. 网络。

【问题】同步失败

检查：

- 模型是否支持 JSON；
- 输出是否被截断；
- 换更稳定的模型；
- 在同步队列重试。

【问题】补全档案没有内容

检查：

- 模型是否返回可解析 JSON；
- 是否还有空白字段；
- 是否有提示信息；
- 换模型。

【问题】阅读模式没有同步按钮

正常。

同步在写作页顶部。

【问题】删除章节没有系统弹窗

正常。

现在使用应用内确认弹窗。

【问题】纯净版和日常版同时打不开

正常。

单实例锁限制。

【问题】端口是什么

正常版使用 app:// 协议，不需要本地端口。

如果看到端口监听，说明启动方式异常。

二十三、注意事项
============================================================

1. AI 生成内容需要校对。
2. 长篇仍可能有连续性错误。
3. 重要作品定期备份。
4. 不建议频繁切换写作模型。
5. 快速同步不生成角色经历。
6. 重要章节建议深度同步。
7. 技能输出不会自动改正文。
8. 自定义技能不执行脚本、不访问网络。
9. 请勿导入侵权内容。
10. 纯净版和日常版数据目录不同。

十九、项目包导入导出
