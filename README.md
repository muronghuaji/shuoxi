# 说戏 Shuoxi

> 本地优先的 AI 长篇小说写作工作台。你只动嘴，AI 动笔；作品、设定和记忆保存在自己的电脑里。

说戏是一款面向长篇小说的桌面写作软件，使用 React + TypeScript + Electron 构建。它把分段续写、完整章节上下文、人物与势力档案、事件状态同步、长篇连续性检查、阅读模式、书签和本地备份整合在一个应用里。

AI 不经过第三方中转服务器：软件通过你自己配置的模型 API 直接请求服务商，作品数据只保存在本机。

## 主要能力

- **分段续写**：按段落生成，不再一次生成整章。
- **完整章节上下文**：1 万字以内章节直接读取完整正文；超过 1 万字时带摘要、开头和最近正文。
- **上下文预算**：8k / 12k / 16k / 24k / 32k / 64k / 128k / 不限制，可查看实际 token 和输入费用；按模型窗口扣掉输出预留，超限前提示。
- **场记分析**：写前先让 AI 拆本场目标、在场角色、认知边界、冲突和必须回收的线。
- **长篇连续性**：人物位置、认知边界、事件、伏笔、关系、时间线锚点。
- **双档同步**：快速同步维护事件和状态；深度同步补角色经历与一致性审查。
- **角色管理**：角色页左侧分类栏；可看全部人物、主要角色、每个势力或散人，点击势力只显示该势力角色，支持搜索、右键移入势力和一键后台补全该势力档案。
- **深度档案**：角色、势力、物种、地点、物品的详细档案，可手动或自动补全。
- **写作技能**：场景诊断、对白打磨、连续性审查、局部润色、章节收尾、去肢体动作腔。
- **自定义技能**：导入/导出 JSON，支持 `SKILL.md` 和 `.zip` 技能包；技能包只读本地资料，不执行脚本；支持重命名和多选启停。
- **阅读模式**：字号、主题、目录、朗读、书签；支持沉浸式隐藏工具栏、章末续读、目录搜索、文字高亮批注和阅读统计。
- **轮椅模式**：紧凑自动写作 Dock，按章数和每章字数区间连续推进。
- **书签**：阅读模式记录滚动位置，写作页可收藏和跳转章节。
- **图片装饰**：自定义书籍封面、角色头像和聊天背景；图片本地压缩保存，不执行脚本。
- **写作模板**：修仙、都市、悬疑、言情、科幻、历史，以及规则怪谈、末世、武侠、现实、娱乐圈、群像题材包，包含故事引擎、角色功能、开局和禁忌。
- **大纲辅助**：开戏可生成故事脊椎和前 5 章大纲；写作页可直接补本章大纲，导演/轮椅模式都能用。
- **灵感库**：随手收下场景、台词、人物、冲突和反转，支持搜索、标签、关联作品、插入章节和标记已用。
- **计费与余额**：DeepSeek 真实余额、充值/赠送拆分；记录缓存命中 tokens、峰谷价格和未定价调用。
- **拖拽导入**：TXT / Markdown 拖入窗口导入小说，ZIP 拖入窗口导入技能包。
- **本地数据**：SQLite/WASM 故事库、本地设置、本地备份、同步队列落盘。
- **正式安装包**：不携带示例作品和测试数据。

## 快速开始

环境要求：

- Windows 10/11 x64
- Node.js >= 18
- pnpm

安装依赖：

```bash
pnpm install
```

开发预览：

```bash
pnpm dev
```

启动 Electron：

```bash
pnpm electron:dev
```

完整检查：

```bash
pnpm check
```

构建可运行目录：

```bash
pnpm pack:dir
```

生成安装包：

```bash
pnpm dist
```

安装包输出：

```text
release/Shuoxi-<version>-setup.exe
```

## 数据位置

Windows 默认用户数据目录：

```text
%APPDATA%\说戏
```

同步队列文件：

```text
%APPDATA%\说戏\sync-queue.json
```

安装包不包含任何用户作品数据。

## 目录结构

```text
src/
  components/        界面组件
  ai.ts              提示词构造、API 调用底层
  aiTask.ts          统一 AI 任务入口、并发、用量
  storyState.ts      事件、状态、经历、档案合并
  syncQueue.ts       同步队列
  archiveQueue.ts    档案补全队列
  entityArchive.ts   实体深度档案统一入口
  skills.ts          内置技能与自定义技能
  bookmarks.ts       书签存储
electron/
  main.cjs           主进程、窗口、协议、队列持久化
  preload.cjs        安全桥接
  appProtocol.cjs    app:// 静态资源与 LLM 代理
docs/                开发与使用文档
build/               图标与构建配置
scripts/             端到端与性能脚本
```
